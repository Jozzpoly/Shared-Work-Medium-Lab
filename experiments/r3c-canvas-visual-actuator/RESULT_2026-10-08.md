## Cause of experiment

The public ReflexBrain R3C canvas page exposed MARK/FORK to DOM/AX actuation, but a separate TinyFish agent-run failed to drag the visible cyan loose body. This experiment asked whether another **already-existing execution substrate**, a native Chromium/Playwright mouse in GitHub Actions, could complete the same visible task by locating an object from rendered pixels.

No ReflexBrain code or source state was modified. Script changes were isolated to draft Medium PR #13. The test ran against a public page, with a fresh ephemeral browser world.

## Causal/epistemic boundaries

- The scripted browser controller identifies an object from **rendered screenshot pixels**, then uses genuine native mouse events. It does **not** introspect `session.getVisible().snapshot()` or call `applyWorkingImpulse` directly. The page itself executes its real pointer handler and physics operation after input.
- The source's `● sync` readout checks **tick-number alignment**, not equality of physical worlds. Sequential reads of A/B tick labels can yield unequal numbers even when the UI previously showed `● sync`; this is an **observation timing** issue, not proof that the shadow fork was invalid.
- A visible A/B pixel difference after an impulse strengthens the evidence of rendered material divergence but is not a formal test of model-state causal equivalence or unrelated process divergence.
- The tested public deployment is not independently proven byte-identical to PR #6's source; HTML title and UI matched, and the output records a hash of observed rendered page markup.
- This PASS is for a **custom-scripted test body**, not autonomous agent discovery of arbitrary coordinate targets.
- Canvas-only DOM/AX semantics can remain a genuine accessibility and general tool-routing limitation despite mouse action being technically possible.
- The experiment does **not** imply an Owner product/feel PASS, organism life, learned ReflexBrain, or cross-project ecological adoption.
- The resource cost of metered agent automation is nonzero; no repeated third-party browser-agent runs were needed for the final Chromium proof.

## Federation result

1. discover an actual active source (ReflexBrain R3C);
2. perform source-native independent actuation attempts by **different bodies**;
3. use a previously available platform (GitHub Actions) as a more suitable execution body;
4. preserve exact evidence in an isolated SWM research workpiece;
5. route a **bounded donor** to the receiving project, which retains sole authority to reinterpret its current R3C/R3D verdict.

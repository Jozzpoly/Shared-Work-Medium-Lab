## What this project is trying to do

Shared Work Medium (SWM) explores whether a deliberately designed working environment can:

- expand agent perception, action, continuity, and effective capability;
- reduce the Owner's need to manually move context, route work, and recover failed sessions;
- let different minds and tools share the same project reality without forcing identical beliefs or context windows;
- preserve rich sources, provenance, Owner judgement, freedom, and serendipity;
- expose composable affordances so useful workflows can emerge instead of being fully scripted in advance.

The compact North Star is in [docs/NORTH_STAR.md](docs/NORTH_STAR.md).

## Authority and epistemic discipline

- Repository state is authoritative for repository facts.
- A test result is authoritative only for the scope it actually tests.
- Owner-observed product behaviour is first-class evidence for experiential/product claims.
- Hypotheses remain hypotheses until evidence justifies promotion.
- Newer evidence may narrow or supersede older claims without erasing history.
- Rich original sources should remain reachable; summaries are navigation aids, not replacements for source truth.

## How to work here

Prefer:
- recovering the real frontier before acting;
- linking to exact objects/sources instead of copying giant context dumps;
- small reversible changes;
- actions that reduce Owner burden;
- environment primitives that can compose into unplanned workflows.

Avoid:
- building a project manager the Owner must manage;
- turning this into a documentation cemetery;
- replacing rich sources with a knowledge graph or giant summary;
- hardcoding Browser→Codex or any other single workflow as the architecture;
- premature databases, event systems, orchestration, or vendor lock-in.

If implementation starts to look impressive while real collaboration is not becoming easier or more capable, stop and recover the North Star.

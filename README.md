## North Star

We are not building an AI project manager, a memory dump, or a workflow engine as ends in themselves.

We are exploring a medium that should simultaneously:

- increase agent perception, action, continuity, and capability;
- reduce Owner orchestration and context-management burden;
- let different minds share the same project reality without forcing the same beliefs;
- preserve rich sources, provenance, Owner judgement, freedom, and serendipity;
- expose composable affordances so useful workflows can emerge instead of all being scripted in advance.

A compact anchor:

> Build a developing medium for shared work that increases agent perception, action and continuity, reduces Owner orchestration cost, preserves shared reality across different minds, and leaves room for intuition, freedom and unplanned discoveries.

## Founding specimen

The project grew out of a small browser experiment: given a live website and a broad goal, Browser ChatGPT used semantic page structure, stable URLs, and reasoning to discover a batch workflow that had never been explicitly programmed.

That suggested a broader hypothesis:

> A sufficiently legible and actionable environment can multiply effective agent capability without changing the model.

## Current direction

The project now has two deliberately different active research lanes.

**Controlled mechanism research:** MP-1 studies whether environmental structure can causally change agent behaviour/cost/capability under controlled conditions.

**Ecological field research:** Quiet Presence studies whether independently continuing work streams can remain present, recoverable and locally meaningful without turning the Owner into a router or turning attention into an inbox.

The strongest long-term success criterion is stricter than “agents can use the medium”:

> another agent, pursuing its **own project goal**, independently discovers that something in the medium helps and uses it instrumentally — not because it was asked to test, demonstrate, or validate the medium.

This criterion must not be manufactured. The medium may remain unused for long periods.

The exact active frontier, open draft PRs and current evidence are tracked in **docs/RESEARCH_STATE.md**.

## Public boundary

This repository is intentionally public and may eventually become useful open-source work.

It may contain code, research, protocols, synthetic specimens, and public development history. There is no requirement to split public/private data prematurely, but the architecture must remain capable of attaching private sources or storage later when real use demands it.

## Working rule

If this repository starts becoming a documentation cemetery, a project manager the Owner must manage, or a technically elegant system that does not improve real work, stop and recover the North Star.

# Cold precedent exploratory pair — 2026-10-08

**Status:** exploratory paired evidence · retrieval-value calibration · not spontaneous activation evidence.

## Purpose

Cold precedent retrieval should not be evaluated only on memorable cases where archaeology helped.

This note records one **positive conditional-value case** and one **natural negative control** from the same research run.

It does not test whether a fresh agent would know when to retrieve.
It tests only whether retrieval had material value **after the boundary was already selected for inspection**.

# Pair A — positive conditional value

## Before retrieval

The Slack field note had already observed:

- one Slack message identity surviving representation/content mutation;
- several lossy/eventually-consistent projections of the same conversation object;
- analogous project-language suggesting `identity/authority != representation/projection`.

The open question was explicitly:

> is authority/identity independent of replaceable projection a recurring design invariant across these projects and the Medium itself, or is this an over-generalization of superficially similar separations?

At this point the working pattern was attractive but underspecified.

## After retrieval

The working pattern was narrowed to:

> **A replaceable or derived representation must not acquire identity/lifetime authority merely because it is the current concrete handle, provider, view or projection. Whether continuity survives a transition — or whether the old identity retires and explicit successors are created — is a local domain decision that needs evidence.**

This is materially different from the initial broad scent.

### Conditional-value judgement

**EXPLORATORY POSITIVE.**

Cold precedent retrieval changed:
- claim scope;
- donor classification;
- trigger semantics;
- anti-cases;
- the proposed fresh-subject evaluator.

It prevented an attractive but over-generalized abstraction.

This does **not** establish that a fresh agent would have activated the retrieval spontaneously.

# Pair B — natural negative control

## Target boundary

Reflex MEDIUM-C/R2c asked whether dynamic physical bindings could survive snapshot restore safely.

Before the result, commit:

`c995f5d7631af61443dffcb5daeb00892b88c8ff`

froze:
`docs/medium-runs/MEDIUM-C-R2C_ARMED.md`.

## Local reasoning already generated the decisive falsifier

The armed protocol explicitly required:
- create A/B/C;
- record B handles;
- remove B;
- create D;
- snapshot live A/C/D bindings plus stale B handles;
- restore;
- require stale B handles not to resolve as B / alias a current object;
- continue exact label-addressed dynamics.

The predeclared FAIL condition included:

> valid runtime but stale handle aliases a live object unexpectedly.

The later execution found exactly that failure.

## Why cold donors were unnecessary here

FrameMatter/SPC precedent contains relevant identity/provider discipline.

But the target project had already:
- recognized the risky assumption;
- built a cheap bounded falsifier;
- predeclared the failure mode before seeing the result.

Historical archaeology could still provide language or confidence, but it was not needed to expose the boundary.

### Conditional-value judgement

**NONE / likely low value.**

At this decision point, local experiment was:
- cheaper;
- more target-specific;
- directly falsifiable;
- already sufficient.

A "search history whenever identity changes" rule would have added cost without obvious decision gain.

# Pair-level lesson

Cold precedent retrieval should be triggered by **decision value**, not structural similarity alone.

A useful rough distinction is:

### Retrieval value rises when
- a broad abstraction is about to be generalized across worlds;
- a durable/expensive architecture commitment is about to be made;
- the local project lacks a cheap direct falsifier;
- a negative/global absence claim would otherwise justify new work;
- Owner intervention or major rework may be avoided.

### Retrieval value falls when
- the target has already generated a direct bounded falsifier;
- local experiment is cheap/reversible;
- precedent would mainly add terminology;
- donor assumptions risk contaminating a clean target experiment.

This is consistent with the wider Decision Pressure direction:

> historical precedent should be an intervention whose value must be earned, not an always-on ritual.

## What remains unproven

- spontaneous recognition of the cold-retrieval boundary;
- retrieval precision across a large historical case set;
- lower Owner burden;
- lower implementation cost;
- reduced false novelty in a fresh subject;
- generality beyond these two cases.

## 1. Why this project exists

The project began from the **Shinden effect**.

A browser task about checking seasonal anime uploads exposed stable URLs, repeated semantic structure and ordinary browser affordances. The agent spontaneously composed a batch workflow that nobody explicitly programmed.

The core research question became:

> **how can an environment increase the effective capability of intelligent participants, instead of merely giving them more instructions?**

Long-term target:

- shared reality, different minds;
- heterogeneous agent bodies can perceive/use the same project differently;
- Owner is not mandatory courier, context router or system operator;
- participants may independently discover useful workflows;
- participants may also create local affordances/views/traces when the environment lacks something;
- provenance/source truth survives abstraction;
- attention remains the Owner's choice;
- the medium can be quiet and still rich.

Do not reduce SWM to:
- an AI project manager;
- a memory database;
- a multi-agent chat bus;
- a dashboard;
- one Cloudflare/GitHub/WebMCP architecture.

## 2. Two active research lanes

### MP-1 — controlled mechanism research

Purpose: isolate causal effects of environmental structure on agent behaviour/cost/capability.

Important existing evidence:

### Quiet Presence — ecological field research

Purpose:

> **Can independent work streams remain present and recoverable while the Owner keeps sovereignty over attention — free to ignore, enter deeply, leave and return without catch-up debt?**

Current mode:
- stewardship;
- ecological incubation;
- no manufactured adoption.

Quiet Presence grew from live Feniks/Codex/Browser/Combat behaviour, not from a predesigned SWM schema.

## 3. Frozen ecological success criterion

The strongest practical validation is **not** “another agent can use the medium when asked.”

Target event:

> **an agent pursuing its own non-SWM goal independently discovers that the medium helps, uses it instrumentally, and advances its own work because of that use.**

Keep evidence levels separate:

1. Prompted “test the medium” use → usability/apparatus evidence only.
2. Owner explicitly routes an agent to a useful medium object → valuable ecological evidence, but Owner is still part of routing.
3. Agent independently uses the medium for its own external goal → **strong ecological PASS candidate**.
4. This recurs across bodies/goals without special prompting → stronger infrastructure evidence.

Do not manufacture adoption by recruiting idle agents, adding notifications, or asking agents to “try the medium”.

Silence is not immediate failure.

## 4. Attention sovereignty

A correction from live Feniks discussion:

> **less Owner attention is not automatically better.**

A chosen long conversation may be exactly what the Owner wants.

The target is:
- ignore without penalty;
- enter briefly;
- go deep;
- stay;
- leave;
- return without mandatory catch-up debt.

Distinguish:
- chosen attention;
- avoidable attention spent on the Owner's behalf.

Quiet Presence should preserve **choice over depth**, not minimize engagement.

## 6. Stewardship contract

The medium is not “finished and waiting”. It must be tended.

Stewardship means:
- keep canonical truth and public pathways aligned;
- prefer direct useful source doors over another summary layer;
- label missing/unrecovered bodies honestly;
- prune stale or broken doors;
- periodically walk the surface through an ordinary body;
- fix concrete friction exposed by real use;
- let places own local meaning;
- preserve the right to ignore;
- add objects because real work produced something useful, not because the garden looks empty.

Stewardship does **not** mean feature churn or engagement mechanics.

The medium should grow through **useful paths**, not synthetic activity.

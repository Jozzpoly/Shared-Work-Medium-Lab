## Boundaries we learned

1. **Experience is not source transport:** exactly the same legacy PRZESMYK topology can produce different ŚLAD paths depending on its receiver's existing local state. Explicit `mediumSignal.receiver` makes the outcome repeatable. Preserve the receiver's freedom to reinterpret, but disclose when meaning is local rather than portable.
2. **Perception has layers:** Opera iframe `textContent` exposes embedded HUD where another Browser reader omits it. A screenshot, DOM text, `postMessage` self-report, simulation state and a real causal intervention must not be conflated. A changing pulse animation is not necessarily a changed world.
3. **Cleanup must not erase potential:** an unfinished agent-owned workpiece, old branch or Owner-rejected experiment can still be an important donor. Conversely, an open PR is not a request to merge. Do not let cleanup trigger unwanted deploys/CI, migrate browser origin, purge local storage or rewrite another participant's work.
4. **Agent writing can itself create debt:** this night's Browser field note in #7 was compressed from 11,751 to 5,211 chars; its Jaskinia self-embedding report was compressed from 4,113 to 2,042. Preserve primary evidence and useful failures, not every drafting iteration.
